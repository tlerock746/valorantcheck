Valorant ID Maker

สร้างภาพสรุปไอดีสำหรับโพสต์ขาย ดาวน์โหลดเป็น PNG

  • ดึงสกิน แรงก์ เลเวล Agent และยอดเงินอัตโนมัติ
  • เลือก Card / Buddy / Spray ที่จะโชว์ได้เอง
  • ปรับขนาดรูป สีกรอบ ใส่ QR / โลโก้ร้าน
เปิดตัวสร้างรูป

เริ่มใช้งานใน 3 ขั้นตอน

เลือกวิธีล็อกอินได้ 2 แบบ ทั้งสองหน้าใช้ระบบเดียวกัน

1

ล็อกอิน

เปิด Riot Client ค้างไว้แล้วกดเชื่อมต่อ หรือล็อกอินผ่านเว็บแล้ววาง URL ที่มี #access_token=...

2

เลือก Region

เลือก ap / na / eu / kr ให้ตรงกับไอดี ถ้าดึงข้อมูลไม่ได้ให้ลองเปลี่ยน Region

3

ดูผลลัพธ์

ดูร้านค้าในหน้า “ร้านค้า” หรือสร้างรูปและดาวน์โหลดในหน้า “ID Maker”

ความปลอดภัย: เซิร์ฟเวอร์รันบนเครื่องคุณเท่านั้น (localhost:3000) ไม่มีการเก็บรหัสผ่านหรือ token ไว้ ใช้เฉพาะกับไอดีของคุณเอง และอย่าส่ง URL ที่มี access_token ให้ผู้อื่น เพราะใช้เข้าถึงไอดีได้ชั่วคราว
